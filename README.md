# CraftOS

CraftOS is a lightweight and interactive web-based operating system designed to simulate a fully functional desktop environment directly inside your web browser. Built using standard HTML, CSS, and modern JavaScript, it features a sleek and responsive user interface complete with a top status bar, a functional taskbar with app launcher icons, and fully draggable, maximizable application windows. The operating system currently includes several built-in applications to enhance your productivity and entertainment experience. These applications consist of a fully operational calculator for mathematical computations, Craft Notes for jotting down text with automatic local storage persistence so your notes are never lost upon closing, Craft Clock featuring global world time zone selection along with a countdown timer and stopwatch, Craft Paint to sketch and draw creations on an HTML5 canvas, and Craft Racer, an endless retro highway driving game where you can dodge traffic obstacles, select custom car colors, and adjust difficulty levels. Additionally, CraftOS includes a simple lockscreen security feature accessible via the logout button in the topbar, ensuring a complete and immersive desktop simulation experience right from your browser.
