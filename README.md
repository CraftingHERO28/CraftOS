# CraftOS

CraftOS is a lightweight web desktop featuring draggable windows, a taskbar, and a lock screen triggered by the top-right Logout button with Berg3.jpg as the wallpaper. It includes five apps: a Calculator, Craft Notes with auto-saving, Craft Clock with timezones, a timer, and a stopwatch, Craft Paint for canvas drawing, and Craft Racer, an endless driving game with customizable car colors and difficulty settings.
